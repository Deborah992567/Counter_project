# Counter

A clean, modern counter app built with vanilla HTML, CSS, and JavaScript.

## Features

- **Increment / Decrement / Reset** with customizable step size
- **Dark & Light mode** with persistent preference
- **Keyboard shortcuts**: `+` increase, `-` decrease, `0` reset, `D` toggle theme
- **History log** tracking every change
- **Copy to clipboard** one click
- **Responsive** design for all screen sizes
- **Color-coded** values (green for positive, red for negative)

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `+` / `=` | Increase |
| `-` | Decrease |
| `0` | Reset |
| `D` | Toggle dark mode |

## How to Run

Open `index.html` in any browser.
