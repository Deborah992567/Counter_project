# Counter

A clean, modern counter app built with vanilla HTML, CSS, and JavaScript.

## Features

- **Increment / Decrement / Reset** with customizable step size
- **Undo** — revert the last action
- **Stats panel** — track total increments, decrements, and resets
- **Counter limits** — optional min/max bounds (can be toggled)
- **Dark & Light mode** with persistent preference
- **Keyboard shortcuts**: `+` increase, `-` decrease, `0` reset, `U` undo, `D` toggle theme
- **History log** tracking every change with color-coded rows
- **Export history** to CSV
- **Copy to clipboard** one click
- **Confetti + sound feedback** on milestones
- **Responsive design** for all screen sizes
- **Color-coded values** (green positive, red negative)
- **Full accessibility** (ARIA labels, focus states, screen-reader support)

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `+` / `=` | Increase |
| `-` | Decrease |
| `0` | Reset |
| `U` | Undo |
| `D` | Toggle dark mode |

## How to Run

Open `index.html` in any browser.
